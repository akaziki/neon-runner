# 霓虹跑酷 Neon Runner

一款赛博朋克霓虹风格的 2D 无尽跑酷网页游戏，纯 HTML5 Canvas + 原生 JS，无需构建、无外部依赖，可直接部署到 GitHub Pages。

## 玩法
- **空格 / ↑ / W**：跳跃（空中再按一次二段跳）
- **↓ / S**：滑铲（空中按下可快速下落）
- **手机**：轻点屏幕跳跃，向下滑动或点击左下角滑铲
- 躲避霓虹方块和激光栅栏，跳过断崖，收集金币（每枚 +50 分），速度会越来越快！
- 右上角按钮可开关音效，最高分保存在本地。

## 本地运行
直接用浏览器打开 `index.html` 即可。
